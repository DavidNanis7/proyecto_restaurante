# Sistema de Gestión de Restaurante 🍽️

Sistema integral desarrollado en Python para la administración de establecimientos gastronómicos.

## 🚀 Funcionalidades
- **Pedidos:** Registro de órdenes por mesa y estado de cocina.
- **Reservas:** Gestión de disponibilidad de mesas.
- **Menú:** CRUD (Crear, Leer, Actualizar, Borrar) de platillos.
- **Caja:** Control de ingresos diarios y cierres.
- **Reportes:** Generación de estadísticas de ventas.

## 🛠️ Instalación
1. Clonar el repositorio.
2. Crear un entorno virtual: `python -m venv venv`.
3. Activar el entorno:
   - Windows: `.\venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`
4. Instalar dependencias: `pip install -r requirements.txt`.
